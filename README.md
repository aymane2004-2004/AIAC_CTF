## 📖 Overview

**AIAC CTF WIKIPEDIA** is a comprehensive, static knowledge base designed for cybersecurity enthusiasts, CTF players, and penetration testers. It serves as a one-stop reference for:

- 🎯 **8 Core CTF Domains** (Crypto, Web, Binary, Forensics, Reverse Engineering, Networking, Cloud, Misc)
- 🛠️ **50+ Essential Tools** with usage context
- 📚 **Glossary** of key hacking terminology
- 🗺️ **Attack Methodology** (Recon → Exploit → Report)
- 🎓 **Structured Learning Path** (Fundamentals → Advanced)
- 💻 **Interactive Terminal Simulation** for practice motivation

---

## ✨ Features

### 1. **Domain Deep-Dives**
Each CTF domain includes:
- Core concepts explained
- Common attack vectors
- Relevant tools
- Badge tags for quick reference

### 2. **Comprehensive Tool Reference**
- Categorized tools (Web, Reverse Engineering, Forensics, Binary Exploitation)
- Purpose and usage context
- Quick lookup table

### 3. **Hacker's Glossary**
- 8+ essential terms defined
- Easy-to-understand explanations
- Covers SQLi, XSS, ROP, JWT, SSRF, and more

### 4. **Learning Path**
- 4-stage structured curriculum
- Progression from fundamentals to advanced topics
- Clear milestones and skill areas

### 5. **Interactive Elements**
- **Matrix Rain Animation** (cyberpunk aesthetic)
- **Smooth Scroll Navigation**
