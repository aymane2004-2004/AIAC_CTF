Cryptography — Breaking Codes & Ciphers

📖 What is Cryptography in CTF?

Breaking encryption algorithms, hashing functions, and encoding schemes. Classical ciphers (Caesar, Vigenère, XOR), modern crypto (RSA, AES, ECC), hashing attacks (MD5/SHA1 collisions).

🔢 Classical Ciphers
Caesar, Atbash, Vigenère, XOR. Frequency analysis & brute force.
🔑 RSA Attacks
Small modulus, Wiener attack, factorization.
🔒 Hashing
Length extension, rainbow tables, collisions.

Essential Glossary — Hacker's Lexicon

🔹 SQL Injection

Malicious SQL queries into input fields to manipulate database.

🔹 XSS

Injecting client-side scripts into web pages. Stored, Reflected, DOM-based.

🔹 Buffer Overflow

Writing beyond buffer boundaries to overwrite return address.

🔹 ROP

Chaining code snippets to bypass NX/ASLR.

🔹 JWT Attack

Algorithm confusion, 'none' signature.

🔹 SSRF

Making server send requests to internal resources.

🔹 Format String

Using %x, %p, %n to leak or write memory.

🔹 XXE

XML External Entity attack to read files/SSRF.
