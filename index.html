Cryptography — Breaking Codes & Ciphers

What is Cryptography in CTF?

Cryptography challenges test your ability to break encryption algorithms, hashing functions, and encoding schemes. Classical ciphers (Caesar, Vigenère, XOR), modern cryptography (RSA, AES, ECC), and hashing attacks (MD5/SHA1 collisions).

Essential Glossary — 50+ Terms You Must Know

🔹 SQL Injection

Malicious SQL queries into input fields to manipulate database.

🔹 XSS (Cross-Site Scripting)

Injecting client-side scripts into web pages.

🔹 Buffer Overflow

Writing beyond buffer boundaries to overwrite return address.

🔹 ROP (Return Oriented Programming)

Chaining code snippets to bypass NX/ASLR.

🔹 JWT Attack

Algorithm confusion, 'none' signature, brute-forcing secrets.

🔹 SSRF (Server-Side Request Forgery)

Making server send requests to internal resources.

🔹 Format String Vulnerability

Using %x, %p, %n specifiers to leak or write memory.

🔹 XXE (XML External Entity)

Exploiting XML parsers to read files or perform SSRF.
