Cryptography — Breaking Codes & Ciphers

What is Cryptography in CTF?

Cryptography challenges test your ability to break, abuse, or bypass encryption algorithms, hashing functions, and encoding schemes. You'll encounter classical ciphers (Caesar, Vigenère, XOR), modern cryptography (RSA, AES, ECC), and hashing attacks (MD5/SHA1 collisions). Understanding mathematical foundations and implementation flaws is key to cracking these challenges.

🔢 Classical Ciphers
Caesar shift, Atbash, Vigenère, Rail Fence, XOR with repeating key. Attack methods: frequency analysis, brute force, known-plaintext.
🔑 Public Key (RSA)
Common vulnerabilities: small modulus, common modulus attack, Wiener attack (small d), factorization (Fermat, Pollard p-1), Hastad broadcast attack.
🔒 Hashing Attacks
Length extension attacks (MD5, SHA1), hash collisions, rainbow tables, salt bypass, preimage attacks.
🔐 Block Ciphers (AES)
ECB mode byte-at-a-time decryption, padding oracle attacks, CBC bit flipping, side-channel timing.
💡 Example: RSA with small exponent (e=3)
Given n = 123456789, ciphertext c = 125, if m³ < n, plaintext m = cube_root(c). Use integer root to recover: flag{small_rsa_exponents_are_critical_weaknesses}

Web Exploitation — Hacking Modern Web Apps

Core Web Vulnerabilities

Web CTFs focus on exploiting flaws in web applications, APIs, and browsers. Attack classes include SQL injection, Cross-Site Scripting (XSS), CSRF, Server-Side Template Injection (SSTI), SSRF, path traversal, JWT tampering, authentication bypasses, and deserialization attacks.

💉 SQL Injection
Classic: ' OR 1=1 -- · Union-based data extraction · Blind boolean/time-based exfiltration · Second-order injection.
🌐 XSS (Cross-Site Scripting)
Stored (persistent), Reflected, DOM-based. Impact: session theft, keylogging, CSRF bypass, account takeover.
⚙️ SSTI (Template Injection)
Jinja2, Twig, Freemarker, Velocity. Abuse template context to execute code, read files, achieve RCE.
🔗 SSRF (Server-Side Request Forgery)
Make server send requests to internal services, metadata endpoints (169.254.169.254), or localhost. Port scanning, cloud credential theft.
🔐 JWT Attacks
Algorithm confusion (RS256 → HS256), 'none' signature, brute-forcing weak secrets, kid path traversal.
💡 Example: SQLi Authentication Bypass
Login form vulnerable. Payload:
username: admin' OR '1'='1' --
password: anything
Result: Bypasses authentication, returns admin session → flag{you_escaped_the_login_wall}

Binary Exploitation (Pwn) — Memory Corruption Mastery

Low-Level Exploitation

Pwning requires exploiting compiled C/C++ binaries. Attack vectors include buffer overflows, format strings, heap overflows, use-after-free, and race conditions. Modern mitigations (ASLR, NX/DEP, PIE, stack canaries, CFG) add complexity requiring ROP, ret2libc, or advanced heap techniques.

📦 Stack Buffer Overflow
Overwrite return address to redirect execution to a win function, shellcode, or ROP chain. Offset calculation is critical.
🔁 ROP (Return Oriented Programming)
Chain small code gadgets (ends with 'ret') from libc or binary to bypass NX/ASLR. Call system('/bin/sh').
📝 Format String Vulnerabilities
Use %p, %x to leak stack values (canaries, libc addresses). Use %n to arbitrarily write to GOT entries.
🏥 Heap Exploitation
tcache poisoning, fastbin dup, unsafe unlink, House of Force/Muney — achieve arbitrary write via malloc metadata.
💡 Example: ret2win (basic 64-bit buffer overflow)
python -c 'print("A"*72 + "\xef\xbe\xad\xde\xef\xbe\xad\xde")' | ./vuln
Explanation: 72 bytes padding + address of win function (little-endian) → prints flag.

Digital Forensics — Artifact & Trace Analysis

Recovering Hidden Traces

Forensic challenges provide disk images, memory dumps, network captures (PCAP), or log files. You'll extract deleted files, analyze network streams, find steganography, reconstruct attacker activities, and recover flags from corrupted or fragmented data.

📡 PCAP Analysis
Wireshark filters (http, dns, tcp.stream), follow TCP streams, extract files transferred, identify suspicious DNS tunneling or exfiltration.
🧠 Memory Forensics (Volatility)
Plugins: pslist (processes), dumpfiles (extract files), hashdump (password hashes), netscan (network connections), malfind (injected code).
🖼️ Image Steganography
LSB hiding in pixels, metadata (exiftool), embedded ZIP/RAR, color palette stego, audio spectrograms (Audacity).
💾 Disk & Carving
Recover deleted files (foremost, scalpel), analyze MFT, unallocated space, HFS+/NTFS artifacts.
💡 Example: Extract hidden ZIP from image
binwalk -e suspicious.jpg → discovers embedded zip archive containing flag.txt
strings suspicious.jpg | grep "flag" → sometimes reveals plaintext flag in metadata.

Reverse Engineering — Under the Hood

Analyzing Binaries Without Source Code

Reverse engineering tasks include crackmes, malware analysis, protocol reversing, and anti-debug bypasses. You'll use disassemblers (Ghidra, IDA), decompilers, debuggers (x64dbg, gdb), and deobfuscation techniques.

📐 Static Analysis
Ghidra/IDA decompilation: identify flag verification functions, look for constants/strings, anti-debug tricks, unpacking.
🐞 Dynamic Analysis
Breakpoints, stepping through execution, patching conditional jumps (NOP/JMP), tracing API calls.
🧩 Obfuscation & Packers
Unpacking UPX/ASPack, deobfuscating control flow flattening, constant unfolding, string decryption.
💡 Example: Crackme keygen
Reverse login binary, find XOR key '0x2A', write Python script to generate valid serial. Flag format example: AIAC{reversing_is_an_art}

Networking & Protocols — Packet Mastery

Network Layer Exploitation & OSINT

Networking CTFs require analyzing custom protocols, packet crafting, and service exploitation. Includes OSINT (public information gathering) from sources like Shodan, DNS records, social media, and Google dorks.

📡 Packet Crafting & Analysis
Scapy to forge TCP/UDP/ICMP packets, replay attacks, manipulate TCP flags, DNS exfiltration detection.
🔍 OSINT (Open Source Intelligence)
theHarvester, Maltego, Shodan, Censys, Google dorks (`intitle:index.of`, `filetype:log`), DNS reconnaissance.
🔄 Protocol Reversing
Reverse unknown binary protocols, analyze custom UDP/TCP communication, extract flags from malformed packets.
💡 Example: Extract flag from DNS tunnel
tshark -r capture.pcap -Y 'dns.qry.name contains "flag"' -T fields -e dns.qry.name → reveals exfiltrated data subdomain: flag{dns_is_leaky}.example.com

Cloud & Container Security

Modern Infrastructure Attacks

Cloud CTFs involve AWS/Azure/GCP misconfigurations: overly permissive IAM policies, exposed S3 buckets, metadata service SSRF, Lambda function injections, container escape via Docker/Kubernetes.

🐳 Docker Container Escape
Privileged container flag, /proc mounts, dirty cow (CVE-2016-5195), exposing docker socket (/var/run/docker.sock).
🔐 IAM & Metadata Misconfiguration
SSRF to EC2 metadata (169.254.169.254/latest/meta-data/iam/security-credentials/) → IAM credentials extraction.
📦 S3 Bucket Exploitation
Public listing, bucket policy misconfig, object ACL, signed URL abuse, versioning & deletion recovery.
☸️ Kubernetes (k8s) Attacks
RBAC privilege escalation, etcd access, service account token abuse, kubelet API exposure.
💡 Example: SSRF to AWS metadata
Vulnerable endpoint: /fetch?url=http://internal
Payload: http://169.254.169.254/latest/meta-data/iam/security-credentials/admin → returns AccessKeyId + SecretAccessKey → cloud takeover.

Miscellaneous & Steganography

Everything Else — Weird Challenges & Stego

Misc covers exotic challenges: audio analysis (spectrograms, SSTV), QR codes, weird encoding (base families, brainfuck, custom bases), esoteric programming languages, custom algorithms, and advanced steganography techniques.

🎵 Audio Steganography
Spectrogram analysis (Audacity, Sonic Visualiser) reveals hidden images/text. SSTV decoding, LSB in audio samples.
🃏 Encoding Hell
Base2/8/16/32/64/85/91, UUencode, XXencode, ROT13/47, brainfuck, JSFuck, custom XOR obfuscation. Decoding layers progressively reveals flag.
📷 Visual Stego
QR codes reconstruction, barcodes, color channel LSB, pixel manipulation, invisible watermarks.
📄 File Format Tricks
Polyglot files (ZIP+PNG), magic bytes spoofing, header/footer analysis.
💡 Example: LSB steganography in PNG
zsteg -a suspicious.png → extracts hidden ASCII message from least significant bits of RGB channels → flag{lsb_secrets_revealed}

Essential Glossary — 50+ Terms You Must Know

🔹 SQL Injection

Malicious SQL queries into input fields to manipulate database. Types: Union, Blind (boolean/time-based), Error-based, Second-order.

🔹 XSS (Cross-Site Scripting)

Injecting client-side scripts into web pages. Stored (persistent), Reflected, DOM-based.

🔹 Buffer Overflow

Writing beyond buffer boundaries to overwrite return address or adjacent variables, redirecting execution flow.

🔹 ROP (Return Oriented Programming)

Chaining small code snippets (gadgets) ending with 'ret' to bypass NX/ASLR and execute arbitrary code.

🔹 ASLR (Address Space Layout Randomization)

Memory randomization mitigation that makes ROP difficult; bypassed via info leaks.

🔹 Canary / Stack Cookie

Random value placed before return address. Overwriting triggers abort. Leak required for overflow.

🔹 JWT Attack

Algorithm confusion ('HS256' vs 'RS256'), 'none' signature, brute-forcing weak HMAC secrets. CVE-2018-0114.

🔹 SSRF (Server-Side Request Forgery)

Making server send requests to internal resources (metadata, localhost, internal IPs) causing information disclosure.

🔹 Format String Vulnerability

Using %x, %p, %s, %n specifiers to leak stack data or arbitrarily write to memory (GOT overwrite).

🔹 GOT Overwrite (Global Offset Table)

Overwrite function pointers in GOT to redirect dynamically linked function calls.

🔹 XXE (XML External Entity)

Exploiting XML parsers to read local files, perform SSRF, or cause DoS (Billion Laughs).

🔹 LFI/RFI (Local/Remote File Inclusion)

Path traversal (../../etc/passwd) or remote inclusion of malicious files leading to RCE.

🔹 Spectrogram

Visual representation of audio frequencies; often used to hide images/text in steganography challenges.

🔹 LD_PRELOAD

Environment variable to hijack library calls; used in local privilege escalation or binary challenges.

🔹 Side-Channel Attack

Exploiting physical or timing information (cache, power consumption, response time) to extract secrets.

CTF Attack Methodology — Standard Workflow

Reconnaissance

Fingerprinting
