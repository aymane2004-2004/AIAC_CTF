Cryptography — Breaking Codes & Ciphers

📖 What is Cryptography in CTF?

Cryptography challenges involve breaking or abusing encryption algorithms, hashing functions, and encoding schemes. You'll encounter classical ciphers (Caesar, Vigenère, XOR), modern cryptography (RSA, AES, ECC), and hashing attacks (MD5/SHA1 collisions).

🔢 Classical Ciphers
Caesar shift, Atbash, Vigenère, Rail Fence, XOR repeating key. Frequency analysis & brute force.
🔑 Public Key (RSA)
Small modulus, common modulus attack, Wiener attack, factorization (Fermat, Pollard p-1).
🔒 Hashing Attacks
Length extension, hash collisions (MD5), rainbow tables, salt bypass.
💡 Example: RSA with small exponent
Given n, e=3, and ciphertext c, if m^3 < n, take cube root → flag{small_rsa_exponents_are_bad}

Web Exploitation — Hacking the Browser

🎯 Core Web Vulnerabilities

Web CTFs test SQL injection, XSS, CSRF, SSTI, SSRF, path traversal, JWT tampering, and authentication bypasses.

💉 SQL Injection
' OR 1=1 --, UNION SELECT, Blind boolean/time-based exfiltration.
🌐 XSS
Stored, Reflected, DOM-based. Steal cookies, keylogging.
⚙️ SSTI
Jinja2/Twig template injection → RCE, file read.
🔗 SSRF
Request to metadata endpoints (169.254.169.254) or internal services.
💡 Example: SQLi Login Bypass
Username: admin' -- , password: anything → bypasses authentication.

Binary Exploitation (Pwn) — Memory Corruption

🖥️ Low-Level Exploitation

Attack vectors: buffer overflows, format strings, heap overflows, use-after-free. Mitigations: ASLR, NX, PIE, canaries.

📦 Stack Overflow
Overwrite return address to win function or shellcode.
🔁 ROP
Chain gadgets from libc to bypass NX/ASLR.
📝 Format String
%p, %x to leak, %n to overwrite GOT entries.
💡 Example: ret2win
python -c 'print("A"*72 + "\xef\xbe\xad\xde")' | ./vuln

Essential Glossary & Attack Terms

🔹 SQL Injection

Malicious SQL queries to manipulate database. Union, Blind, Boolean, Error-based.

🔹 XSS (Cross-Site Scripting)

Inject client-side scripts. Stored, Reflected, DOM-based.

🔹 Buffer Overflow

Write beyond buffer boundaries to overwrite return address.

🔹 ROP (Return Oriented Programming)

Chain gadgets to bypass NX/ASLR.

🔹 Steganography

Hide data within images/audio. LSB, metadata, frequency domain.

🔹 JWT Attack

Algorithm confusion, none signature, brute-force secrets.

🔹 SSRF

Server-Side Request Forgery to internal resources.

🔹 Format String

%x, %p to leak, %n to overwrite memory.

🔹 XXE

XML External Entity attack to read files/SSRF.

🔹 LFI/RFI

Local/Remote File Inclusion via path traversal.
